## Какие сведения обрабатываются
Приложение содержит учебные записи студентов: ФИО, логин, группу, контактный телефон,
электронную почту и адрес (если добавлены). Данные учебной сборки хранятся локально в SQLite
на устройстве. Пароли хранятся в виде производных PBKDF2 с индивидуальной солью.

## Мониторинг
При подключении Firebase в отдельной настройке проекта могут собираться диагностические
сведения о сбоях, устройстве, сеансах и событиях использования. Перед реальной публикацией
проверьте конфигурацию Crashlytics/Analytics и уточните эти категории по фактическим данным.

## Передача данных
Без конфигурации Firebase приложение не отправляет студенческие записи на удалённый сервер.
Поле API_BASE_URL в данном учебном проекте — заглушка, запросы туда не отправляются.

## Защита и хранение
Локальную базу данных нельзя считать шифрованной; доступ ограничен механизмами Android.
Для настоящих персональных данных необходимы отдельные меры защиты и законное основание.
При удалении приложения ОС обычно удаляет локальные данные вместе с ним.
